# Restaurant Order Management with Kitchen Queue

## Project Description
A C-based Restaurant Order Management System designed to manage restaurant orders, kitchen queues, order status, billing, and sales reports efficiently.

## Features
- Store and manage restaurant menu items.
- Accept customer orders with table numbers and quantities.
- Generate unique order IDs.
- Manage kitchen orders using a queue.
- Update order status (Preparing, Ready, Served, Cancelled).
- Calculate bills including taxes and service charges.
- Generate itemized invoices.
- Display most ordered items and daily revenue reports.
- Analyze order frequency using searching and sorting.

## Technologies Used
-ByteXL (Nimbus)

## Concepts Used
- Structures
- Arrays and Strings
- Functions
- Pointers
- Dynamic Memory Allocation
- Queue Data Structure
- File Handling
- Searching and Sorting Algorithms
- Loops and Conditional Statements

## How to Run
1. Download or clone this repository.
2. Open the project in a C compiler.
3. Compile the source code.
4. Run the executable file.
5. Follow the menu-driven instructions.

## Project Objective
The main objective of this project is to develop a restaurant management system that simplifies order processing, kitchen queue management, billing, and sales analysis using C programming concepts.
